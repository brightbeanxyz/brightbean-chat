{% comment %} The sidebar — the product's whole chrome. There is no top header: the workspace switcher, the primary navigation, notifications and the account menu all live here. 240px on a desktop, collapsing to 60px, and an off-canvas drawer below `lg`. **The three legs of the anti-flash contract.** The collapse is persisted, so a page can start in either of two widths and the wrong one flashes before Alpine boots. Three pieces stop that, and they only work together: a pre-paint script in base.html's head stamping `sidebar-is-collapsed` on (leg 1), the `.sidebar-initial` width mirror (leg 2, in base.html's head for the width and in styles.css for everything else), and the `x-init` below, which strips both markers the moment Alpine takes over (leg 3). Remove one and you get either a flash on every load or a sidebar frozen at its pre-paint width forever — `.sidebar-initial`'s width is unlayered and beats the `lg:w-*` utility Alpine binds. TestTheSidebar fails the page if any leg goes missing. **One copy of the nav, still.** The drawer does not break the invariant the old bottom tab bar existed to protect: it is this same
, repositioned by a media query and slid in with a transform. A *second* nav would mean a second `nav-badge-inbox`, and an out-of-band swap only ever finds the first — apps/notifications/tests/test_shell.py forbids it. **No `{% templatetag openblock %} block sidebar_nav {% templatetag closeblock %}`.** Studio has one and every settings layout overrides it, which is how its badge targets came to go missing on whole archetypes. Here the settings nav is a second column beside this one, and apps/notifications/tests/test_shell.py::test_no_layout_replaces_the_navigation_any_more fails the moment a layout replaces it. `wsOpen` is local again. It sat on the shell wrapper while two controls opened one panel — the header's workspace button and the rail's logo mark — and with the header gone there is one trigger, inside the panel's own wrapper, so the `data-ws-toggle` guard the two-trigger arrangement needed is gone with it. {% endcomment %}
