{% comment %} The icon rail — the product's whole primary navigation. Replaces the 240px collapsible sidebar. There is no collapsed state any more: the rail *is* the narrow state, so the three-part anti-flash contract that used to live in base.html's head (pre-paint script, .sidebar-initial mirror CSS, x-init handover) is gone rather than reduced. Nothing is persisted, so there is no width to restore before paint. Below `lg` this same element becomes a bottom tab bar — see the media query in styles.css. Deliberately not an off-canvas drawer: a drawer needs a second copy of the nav, and a second copy means a second `nav-badge-inbox`, which is both how `notification-badge-mobile` came to exist and what apps/notifications/tests/test_shell.py forbids ("each id exactly once"). One rail, repositioned. The workspace switcher's panel is in the header, where there is room for a name. This is the workspace's mark, and it opens that same panel. **`data-ws-toggle` is what makes it work.** The panel's wrapper in the header carries `@click.away`, which fires for any click outside it — including a click on this button, in the same event that opens the panel. The two cancelled out and this button did nothing at all. The header's guard skips clicks on anything marked `data-ws-toggle`, so a trigger may live outside the panel it opens; any future one needs the same attribute. When there is only one workspace the header renders no panel, so this renders as a plain mark rather than a button that toggles a state nothing shows. {% endcomment %}
