{% comment %} The messaging-platform glyph. There is exactly ONE of these. DEVIATION 3 of the L1-B brief. Studio ships two copies that have genuinely drifted apart: templates/partials/_platform_icon.html (hard-coded brand hex, a semantic sm/md size API, a globe fallback) and templates/social_accounts/partials/_platform_icon.html (currentColor, raw Tailwind numeral sizes, NO fallback, and a 3.5 KB base64 JPEG raster for one platform). Their Instagram, Bluesky, Mastodon and Pinterest paths are all subtly different, and only one of them knows about Twitter. This one takes the union of what each did better: * `currentColor`, so the caller tints per context. A chat channel shows up on a white sidebar row, on a coloured chip, inside a filter dropdown and in a conversation header — a brand-hex-only icon can only serve the first. Pair with .pi- (tinted chip, white glyph) or .pi-ink- (brand-coloured glyph, no chip) from the design system. * the named sm/md size API rather than raw Tailwind numerals, so a caller cannot ask for a size the Tailwind build never generated. * a real fallback, so an unrecognised platform key renders a neutral glyph instead of an empty box.
