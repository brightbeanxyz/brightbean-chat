Inbox rules

A rule reads every message that arrives and files, assigns or closes the conversation it belongs to. It runs before any flow replies, and it keeps running even where somebody has paused automation on a thread.

Triggers stop at the first match. Rules do not: every rule that matches applies, in the order below.
