Every string here comes from RuleSummary, which is assembled server-side from this workspace's own label, member and platform names — the stored condition json never reaches the page. An id that no longer resolves prints "(deleted)" rather than vanishing: a rule quietly describing itself as doing less than it does is how somebody ends up debugging automation that is not in front of them. Five equal buttons per row became two arrows, one named action and a "…". The arrows stay visible because they are the drag handle's keyboard twin, and hiding a keyboard path behind a menu is not the same trade as hiding a twice-a-year action. {% endcomment %}
