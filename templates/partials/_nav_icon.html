{% comment %} Nav glyph, 18px by default. `name` comes from a NavItem.icon in apps.common.context_processors; an unknown name renders a neutral dot rather than nothing, so a mistyped key is visible instead of silently collapsing the row's layout. `icon_size` overrides the 18px for callers outside the nav rows — the workspace switcher's dropdown sets 14px, because 18px against its 12px labels made the settings row taller than the workspace rows above it. Named `icon_size` rather than `size` so an ambient `size` in a parent context cannot resize a glyph by accident: `{% include %}` without `only` inherits everything. The stroke width is 1.5 for every glyph, set once on the wrapper. Most of these are feather outlines drawn at 2; four of them (dashboard, inbox, broadcasts, automations) are not, and a 2 beside a 1.5 in the same column reads as a rendering fault rather than as two icon sets. One weight, applied here. The main nav no longer has a Flows row or a Sequences row — they are one Automations row — but neither glyph is dead. `flows` still draws the workspace settings "Inbox rules" row (a rule is a small flow), and both names are used by apps/billing/plans.py and apps/billing/selectors.py for plan features and the usage table.
