{% extends "layouts/workspace_settings.html" %} {% load common_extras %} {% comment %} Channels, as cards rather than as a table. Three things the redesign changed, in order of how much they matter. **Health is a sentence.** "Needs reauth" in a status column beside a separate "2 days ago" cell made a reader assemble the meaning themselves. It now reads "Needs reconnecting · nothing received for 2 days" — the two facts already joined, with a dot carrying the colour. Webhook health is genuinely two facts (a bot pointed at the wrong URL looks exactly like a bot nobody has messaged), which is why both are in the line. **A broken channel gets a banner.** It is the most consequential thing this page can say, and it used to be one word in a cell halfway down a table. **The webhook URL and the platform account id are gone from the list.** They are machine strings a person needs once, during setup, and printing them on every row made the page look like a configuration dump. They live on the connection's own page now, which is where somebody pasting one into a console is already standing. (The redesign's fifth principle: no ids in the UI.) {% endcomment %} {% block title %}Channels · BrightBean Chat{% endblock %} {% block content_wrap %}{% endblock %} {% block content %}
