BrightBean Chat talks to Meta's Cloud API directly — there is no messaging provider in between. What you need is a WhatsApp Business Account, a phone number registered on it, and a permanent system user token. The token is the whole credential, so it is stored encrypted and never shown again.

Before you paste

  1. In Business Manager, open WhatsApp Accounts and copy the WhatsApp Business Account ID.
  2. Open the account's Phone numbers tab and copy the phone number ID — the numeric API id, not the number itself.
  3. Create a system user with access to the account, and generate a permanent token with whatsapp_business_messaging and whatsapp_business_management.

What happens next

We read the phone number back from Meta to check the token and learn how the number displays, then subscribe this app to the account's webhooks. Nothing is stored until that first call succeeds, and the connection is removed again if the subscription fails — a number Meta will not deliver for is not a connection.

Meta delivers every WhatsApp event in this deployment to:

{{ webhook_url }}

Set that URL, and a verify token matching PLATFORM_WHATSAPP_VERIFY_TOKEN, on your Meta app's WhatsApp → Configuration page, and subscribe to the messages field. The URL has to be reachable over public HTTPS with a valid certificate. Full setup notes are in docs/channels/whatsapp.md.
