Include this with `only`: the size is read from an argument, and without `only` an unrelated `size` in the surrounding context would silently resize the mark. Args: workspace: optional object with .icon and .name. size: "sm" (28px) or "md" (30px, default). TestLogoSizing pins every modifier this file emits to a rule that exists in the compiled bundle, so the next one cannot rot the same way.
