{% load static %}{% comment %} The product/workspace mark. Renders the workspace icon when there is one, the workspace's initial when there is not, and the BrightBean Chat logo when there is no workspace at all (the anonymous and pre-tenancy case). Include this with `only`: the size is read from an argument, and without `only` an unrelated `size` in the surrounding context would silently resize the mark. Args: workspace: optional object with .icon and .name. size: "sm" (28px), "md" (30px, the base class's own size, and the default) or "lg" (26px and a rounder corner — the rail's workspace button, which is the only size any caller actually passes today). The size modifier is a class from the design system, not a Tailwind utility. .sidebar-logo-mark is unlayered CSS and Tailwind's w-7/h-7 live in @layer utilities, so the utility loses the cascade and never applies. It is derived from the argument rather than branched on per size. Branching tested only for "sm", so size="lg" — what both of the rail's includes pass — fell through to the unmodified 30px mark and .sidebar-logo-mark-lg was emitted nowhere at all: the same silent no-op the stylesheet says size="sm" once was.
