Authentication

Every request carries an API key issued from Settings → Organization → API keys:

Authorization: Bearer {{ token_prefix }}…

A key is scoped to exactly one workspace; there is no cross-workspace call and no way to widen a key after issuance. Requests without a valid key get 401. Outside development a key sent over plain HTTP is refused — it has already been logged by every hop that saw it.

Requests

JSON in, JSON out. Bodies are capped at {{ max_body_bytes }} bytes, and unknown keys are rejected rather than ignored — a typo in a field name is a 422, not a silently dropped value.

Pagination

Every list endpoint answers with the same envelope:

{
  "data": [ … ],
  "has_more": true,
  "next_cursor": "eyJvIjo1MH0"
}

Pass ?limit= (1–{{ max_limit }}, default {{ default_limit }}) and ?cursor=. The cursor is opaque: echo back next_cursor and never construct one. Keep paging while has_more is true. There is no total — counting a workspace's contacts costs more than the page does.

Verifying a delivery

The signature is v1= followed by the hex HMAC-SHA256, over the timestamp, a literal dot, and the raw request body — in that order, on the bytes you received, before any JSON parsing. 

import hashlib, hmac, time

def verify(secret, headers, raw_body, tolerance={{ timestamp_tolerance }}):
    timestamp = headers["{{ timestamp_header }}"]
    presented = headers["{{ signature_header }}"]
    if abs(time.time() - int(timestamp)) > tolerance:
        return False
    signed = timestamp.encode() + b"." + raw_body
    expected = "v1=" + hmac.new(secret.encode(), signed, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, presented)

Compare in constant time, check the timestamp, and treat {{ delivery_header }} as the deduplication key — delivery is at-least-once. Answer 2xx to acknowledge. A delivery that fails is retried on a backoff; after {{ failure_limit }} consecutive failed deliveries the endpoint is switched off and the workspace admins are notified.
