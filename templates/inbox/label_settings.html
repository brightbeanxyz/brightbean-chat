Labels

{% endblock %} {% block content %}

Labels file a conversation. They are the inbox's own filing system, and they are not contact tags: a tag like “VIP” follows a person across every channel they use, while a label like “waiting on shipping” is true of one thread and stops being true when it is answered. Inbox rules can add labels automatically. Deleting a label removes it from every conversation carrying it.
