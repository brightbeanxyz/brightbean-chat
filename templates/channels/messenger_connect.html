Before you start

  1. Create a Meta app of type Business and add the Messenger and Facebook Login for Business products to it.
  2. Add this exact redirect URI to Facebook Login for Business → Valid OAuth Redirect URIs:
    {{ callback_url }}
  3. Put the app's ID and secret into Settings → Credentials, or into PLATFORM_MESSENGER_CLIENT_ID and PLATFORM_MESSENGER_CLIENT_SECRET.
  4. Set PLATFORM_MESSENGER_VERIFY_TOKEN and paste the same value into the Messenger webhook's Verify token field.
