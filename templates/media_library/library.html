Filters are plain links so the state lives in the querystring and a view is bookmarkable; search, uploads and mutations swap `#media-grid` through htmx and nothing else. No inline event handlers anywhere. The CSP (config/settings/base.py) allows 'unsafe-eval' for Alpine's x-* expressions but NOT 'unsafe-inline', so an `onclick=` attribute silently does nothing — the failure mode is a button that looks fine and is inert.
